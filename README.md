
# BookNest

Учебный проект по дисциплине WEB 3210
«Современные веб-технологии».

## Лабораторная работа 1

- index.html — каталог книг.
- book.html — карточка книги.
- loan.html — форма выдачи книги.

## Технологии

- HTML5
- Семантическая разметка
- HTML-формы и встроенная валидация

## Запуск

Открой index.html в браузере.
